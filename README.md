# Prompt para Apoio à Auditoria de Descrições Cirúrgicas no SUS com LLMs

Este repositório disponibiliza o prompt utilizado no trabalho
"LLMs no Apoio à Auditoria de Descrições Cirúrgicas no SUS:
Uma Análise do Potencial e das Limitações".

## Prompt

A versão utilizada nos experimentos apresentados no artigo está disponível em:

`prompts/prompt_auditoria_v1.md`

## Versão

Versão: v1.0  
Data: setembro de 2026

Esta versão corresponde ao prompt utilizado nos experimentos reportados
no artigo.

## Contexto

O prompt foi desenvolvido para apoiar a análise de descrições cirúrgicas,
incluindo identificação do procedimento realizado, consulta ao SIGTAP,
verificação de informações associadas e identificação de lacunas ou
inconsistências documentais.

## Observações

O repositório não contém dados reais de pacientes ou prontuários clínicos.
